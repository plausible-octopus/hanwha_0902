# 0910 필기

## Python 데이터 유형 복습

### 1. list

- 여러 개의 값을 순서대로 저장
- 대괄호 `[]` 사용
- 값의 순서가 있음
- 인덱스로 값에 접근

형식

`[값1, 값2, 값3]`

예시 형태

`["apple", "banana", "orange"]`

---

### 2. dict

- `key : value` 형태로 데이터 저장
- 중괄호 `{}` 사용
- 순서보다 key를 이용해서 값을 찾는 구조

형식

`{"key": value}`

쉽게 기억

`key → 이름표`

`value → 실제 데이터`

---

### 3. 다중 dict / 중첩 dict

- dict 안에 또 다른 dict가 들어가는 구조
- 여러 단계로 구성된 데이터를 표현할 때 사용
- 상위 key → 하위 key 순서로 접근

형식

`{"key1": {"key2": value}}`

접근 방식

`dict["key1"]["key2"]`

---

## 핵심 정리

- `list` → `[]`
- `dict` → `{}`
- `dict` → `key : value`
- 중첩 dict → `{}` 안에 또 `{}`
- list → 순서로 찾기
- dict → key로 찾기
