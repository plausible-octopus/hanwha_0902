# 0910 필기

## Python 데이터 유형 복습

### 1. list

- 여러 개의 값을 순서대로 저장
- 대괄호 `[]` 사용
- 값의 순서가 있음
- 인덱스로 값에 접근

형식

`[값1, 값2, 값3]`

예시 형태

`["apple", "banana", "orange"]`

---

### 2. dict

- `key : value` 형태로 데이터 저장
- 중괄호 `{}` 사용
- 순서보다 key를 이용해서 값을 찾는 구조

형식

`{"key": value}`

쉽게 기억

`key → 이름표`

`value → 실제 데이터`

---

### 3. 다중 dict / 중첩 dict

- dict 안에 또 다른 dict가 들어가는 구조
- 여러 단계로 구성된 데이터를 표현할 때 사용
- 상위 key → 하위 key 순서로 접근

형식

`{"key1": {"key2": value}}`

접근 방식

`dict["key1"]["key2"]`

---

## 핵심 정리

- `list` → `[]`
- `dict` → `{}`
- `dict` → `key : value`
- 중첩 dict → `{}` 안에 또 `{}`
- list → 순서로 찾기
- dict → key로 찾기

# 0910 - Streamlit & FastAPI 연결

## 1. Streamlit과 FastAPI

- **Streamlit** → 사용자가 보는 화면(Frontend)
- **FastAPI** → 데이터를 받아 처리하는 서버(Backend)
- 각각 별도의 서버이기 때문에 각각 실행 필요

### 실행

FastAPI

```bash
python -m uvicorn fast_main:app --reload
```

- 기본 주소: `http://127.0.0.1:8000`
- Swagger: `http://127.0.0.1:8000/docs`

Streamlit

```bash
streamlit run app.py
```

챗봇 화면

```bash
streamlit run app_02.py
```

- 기본 주소: `http://localhost:8501`

---

## 2. Streamlit → FastAPI 데이터 전송

Streamlit에서 데이터를 만들고 FastAPI로 POST 요청을 보냄.

```python
payload = {
    "name": name,
    "age": age
}

response = requests.post(
    f"{FASTAPI_URL}/predict",
    json=payload
)
```

### 데이터 흐름

`Streamlit 입력 → POST 요청 → FastAPI 처리 → 응답 → Streamlit 출력`

- `payload` → 서버에 보낼 데이터
- `requests.post()` → POST 요청 전송
- `response` → FastAPI가 보내준 응답
- `response.json()` → JSON 응답을 Python 데이터로 변환
- `status_code == 200` → 요청 정상 처리

---

## 3. FastAPI에서 데이터 받기

```python
class UserInput(BaseModel):
    name: str
    age: int


@app.post("/predict")
def process_data(data: UserInput):
    is_adult = data.age >= 19

    message = f"안녕하세요 {data.name}님! " + (
        "성인입니다." if is_adult else "미성년자입니다."
    )

    return {
        "status": "success",
        "result_message": message,
        "is_adult": is_adult
    }
```

- `BaseModel` → 들어오는 데이터의 형식과 타입 검증
- `@app.post("/predict")` → `/predict`로 들어오는 POST 요청 처리
- `return` → 처리 결과를 다시 Streamlit로 전달

## 4. Streamlit 챗봇

```python
user_message = st.chat_input("메시지를 입력하세요")
```

- `st.chat_input()` → 사용자 채팅 입력

```python
with st.chat_message("user"):
    st.write(user_message)
```

- 사용자 메시지를 채팅 형태로 출력

### FastAPI로 채팅 전송

```python
payload = {
    "message": user_message
}

response = requests.post(
    f"{FASTAPI_URL}/chat",
    json=payload
)
```

- Streamlit에서 입력한 메시지를 `/chat`으로 전송

## 5. FastAPI 챗봇 API

```python
class ChatInput(BaseModel):
    message: str


@app.post("/chat")
def chat(data: ChatInput):
    user_message = data.message

    print("받은 채팅:", user_message)

    reply = f"입력한 내용은 '{user_message}' 입니다."

    return {
        "reply": reply
    }
```

- Streamlit에서 보낸 `message`를 FastAPI가 받음
- `print()` → 백엔드 터미널에서 받은 데이터 확인
- `reply` → 처리한 결과를 Streamlit에 반환

### 챗봇 데이터 흐름

`사용자 → Streamlit → FastAPI /chat → 데이터 처리 → Streamlit → 사용자`

FastAPI 터미널에서 확인:

```text
받은 채팅: 안녕하세요
POST /chat HTTP/1.1 200 OK
```

- `200 OK` → 요청 정상 처리

## 6. 동기 / 비동기

### 동기 (Synchronous)

- 하나의 일을 시작하면 그 일이 끝난 뒤 다음 일 처리
- 쉽게 기억: **주어진 일을 끝까지 해결하고 다음 일**

### 비동기 (Asynchronous)

- 하나의 일이 끝날 때까지 기다리지 않고 다른 일을 처리
- 식당에서 여러 주문을 받아두고 **음식이 완성되는 대로 제공하는 방식**
- 일이 몰릴 때 기다리는 시간을 활용할 수 있어 효율적
- 서버의 불필요한 대기를 줄여 과부하를 피하고 효율적으로 처리 가능

### 핵심

- 동기 → 하나 끝내고 다음 일
- 비동기 → 기다리는 동안 다른 일 처리
- FastAPI의 `async def`와 연결되는 개념
