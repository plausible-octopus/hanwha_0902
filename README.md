## 💡 핵심 정리

Python 프로젝트에서는 필요한 경우 프로젝트별 가상환경을 만들어 패키지를 독립적으로 관리한다.

GitHub에는 실습 코드와 학습 내용을 정리한 문서를 중심으로 관리한다.
