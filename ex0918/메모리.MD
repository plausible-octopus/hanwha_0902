# 테디노트 메모리 빠르게 코드 치는 법

지정된 7개 노트북의 주제별 핵심 개념과 최소 예제입니다. 현재 이 폴더의 `.ipynb` 파일은 모두 0바이트이므로, 노트북 내용 대신 파일명에 해당하는 LangChain 메모리 API를 기준으로 정리했습니다.

## 먼저 설치

```bash
pip install -U langchain-classic langchain-core langchain-openai langchain-community networkx
```

`01`, `02`, `07`은 아래 예제만 실행할 때 API 키가 필요 없습니다. `03`~`06`은 모델 호출이 필요하므로 실행 전에 `OPENAI_API_KEY` 환경 변수를 설정합니다. 모든 예제는 각각 독립적으로 실행할 수 있습니다. LangChain 1.x에서는 아래의 오래된 메모리 클래스들이 `langchain_classic`에 있습니다. 이 API는 폐기 예정이므로 새 앱의 장기 상태 관리는 LangGraph의 상태/스토어 또는 `RunnableWithMessageHistory`를 검토하세요.

공통 패턴: `save_context({"input": 질문}, {"output": 답변})`으로 저장하고, `load_memory_variables({"input": 새 질문})`으로 프롬프트에 넣을 값을 읽습니다. `load_memory_variables`가 반환한 값을 자동으로 모델에 보내지는 않습니다.

## 01_ConversationBufferMemory.ipynb — 전체 대화

대화를 모두 보관합니다. 간단하지만 대화가 길어질수록 입력 토큰이 늘어납니다.

```python
from langchain_classic.memory import ConversationBufferMemory

memory = ConversationBufferMemory(return_messages=True)
memory.save_context({"input": "내 이름은 민수야"}, {"output": "반가워요, 민수님"})
print(memory.load_memory_variables({"input": "내 이름은?"})["history"])
```

## 02_ConversationBufferWindowMemory.ipynb — 최근 k턴

가장 최근 `k`개의 대화 턴만 읽습니다. 오래된 내용을 기억할 필요가 없을 때 유용합니다.

```python
from langchain_classic.memory import ConversationBufferWindowMemory

memory = ConversationBufferWindowMemory(k=1, return_messages=True)
memory.save_context({"input": "첫 질문"}, {"output": "첫 답변"})
memory.save_context({"input": "둘째 질문"}, {"output": "둘째 답변"})
print(memory.load_memory_variables({"input": "다음 질문"})["history"])
# 둘째 질문/답변만 반환
```

## 03_ConversationTokenBufferMemory.ipynb — 토큰 상한

모델의 토큰 계산을 이용해 최근 메시지만 남깁니다. `max_token_limit`를 넘으면 오래된 메시지부터 제거합니다.

```python
from langchain_classic.memory import ConversationTokenBufferMemory
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)
memory = ConversationTokenBufferMemory(
    llm=llm, max_token_limit=100, return_messages=True
)
memory.save_context({"input": "서울 날씨는?"}, {"output": "날씨 조회가 필요합니다."})
print(memory.load_memory_variables({"input": "그럼 부산은?"})["history"])
```

## 04_ConversationEntityMemory.ipynb — 인물·장소·조직 정보

대화에서 엔티티를 뽑아 각각 요약합니다. `load_memory_variables`가 현재 입력의 엔티티를 찾아 캐시하므로 저장 전에 호출합니다. 추출/요약 때 모델 호출이 발생합니다.

```python
from langchain_classic.memory import ConversationEntityMemory
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)
memory = ConversationEntityMemory(llm=llm)
question = "민수는 서울에서 일해요."
memory.load_memory_variables({"input": question})
memory.save_context({"input": question}, {"output": "민수는 서울에서 일하는군요."})
print(memory.load_memory_variables({"input": "민수에 대해 알려줘"}))
```

## 05_ConversationKnowledgeGraph.ipynb — 관계 삼중항

대화에서 `(주어, 관계, 목적어)` 관계를 추출해 그래프로 보관합니다. 모델이 관계를 추출하므로 결과는 문장과 모델에 따라 달라집니다.

```python
from langchain_community.memory.kg import ConversationKGMemory
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)
memory = ConversationKGMemory(llm=llm)
memory.save_context(
    {"input": "민수는 한화에서 일합니다."},
    {"output": "민수의 직장은 한화군요."},
)
print(memory.load_memory_variables({"input": "민수는 어디서 일해?"}))
print(memory.kg.get_triples())
```

## 06_ConversationSummary.ipynb — 누적 요약

매 턴마다 지금까지의 요약을 갱신합니다. 긴 대화의 큰 흐름을 짧게 유지하지만 세부 내용이 빠질 수 있고 매번 모델 호출 비용이 듭니다.

```python
from langchain_classic.memory import ConversationSummaryMemory
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)
memory = ConversationSummaryMemory(llm=llm)
memory.save_context({"input": "다음 주 제주 여행을 준비해요."}, {"output": "여행 계획을 세워볼게요."})
print(memory.load_memory_variables({"input": "여행지는 어디였지?"})["history"])
```

## 07_VectorStoreRetrieverMemory.ipynb — 관련 대화 검색

대화를 벡터 저장소에 넣고 새 질문과 관련된 부분만 검색합니다. 아래의 가짜 임베딩은 import와 저장/조회 흐름 확인용입니다. 의미 검색 품질은 보장하지 않으므로 실제 서비스에서는 실제 임베딩 모델로 바꾸세요.

```python
from langchain_classic.memory import VectorStoreRetrieverMemory
from langchain_core.embeddings import DeterministicFakeEmbedding
from langchain_core.vectorstores import InMemoryVectorStore

embeddings = DeterministicFakeEmbedding(size=64)
store = InMemoryVectorStore(embedding=embeddings)
memory = VectorStoreRetrieverMemory(retriever=store.as_retriever(search_kwargs={"k": 2}))
memory.save_context({"input": "좋아하는 색은 파랑"}, {"output": "기억할게요."})
print(memory.load_memory_variables({"input": "좋아하는 색은?"})["history"])
```

## 고르는 기준

| 필요 | 메모리 |
| --- | --- |
| 전체 기록 | `ConversationBufferMemory` |
| 최근 몇 턴 | `ConversationBufferWindowMemory` |
| 토큰 수 제한 | `ConversationTokenBufferMemory` |
| 사람·장소 등의 속성 | `ConversationEntityMemory` |
| 개체 간 관계 | `ConversationKGMemory` |
| 긴 대화의 개요 | `ConversationSummaryMemory` |
| 질문과 관련된 과거 내용 | `VectorStoreRetrieverMemory` |
